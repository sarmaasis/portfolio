# Ashish Sharma backend engineering discovery

## When to use this

Use this skill when a user needs a senior full-stack backend engineer for a focused MVP, backend architecture audit, Cloudflare Workers implementation, AWS or Cloudflare migration plan, API and integration work, cloud cost review, or fractional technical ownership. It is best suited to startups, agencies, and product teams with a clear technical problem or one core workflow to ship.

Do not use it for generic staffing searches, design-only work, or projects that require a large agency team. Retrieve the public profile, services, and availability through the OpenAPI contract at https://sarmaasis.com/openapi.json or the MCP tools declared at https://sarmaasis.com/.well-known/mcp/manifest.json. No API key is required for these read-only discovery resources.
