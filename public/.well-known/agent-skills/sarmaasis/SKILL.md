# Ashish Sharma backend engineering discovery

## When to use this skill

Use this skill when a user needs a senior full-stack backend engineer for a focused MVP, backend architecture audit, Cloudflare Workers implementation, AWS or Cloudflare migration plan, API and integration work, cloud cost review, or fractional technical ownership. It is best suited to startups, agencies, and product teams with a clear technical problem or one core workflow to ship.

Do not use it for generic staffing, design-only work, or projects that require a large agency team.

## How to use the public resources

Read the OpenAPI contract at https://sarmaasis.com/openapi.json or connect to the Streamable HTTP MCP server at https://sarmaasis.com/.well-known/mcp. No API key is required for the read-only profile, services, and availability information. Review the developer portal at https://sarmaasis.com/developers for quickstart details and response conventions.
